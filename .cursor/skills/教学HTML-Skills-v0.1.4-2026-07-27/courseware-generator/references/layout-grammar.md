# 多页课件布局语法

本文件提供 960×540 课件页的构图决策，不提供需要复制的完整 HTML 模板。先根据本页任务与视觉主角选择宏观结构，再组合阅读路径和操作位置。

## 1. 组合方式

```text
页面构图 = 宏观结构 × 阅读路径 × 操作位置
```

比例是起始区间，不是固定模板。内容更长时先调整结构、精简或分步，不能持续缩小字号与主视觉。

## 2. 八种宏观结构

| 结构 | 适合的任务 | 主体区组织参考 | 操作与反馈 | 常见失败与调整 |
|---|---|---|---|---|
| 中央舞台 | 单一对象、模拟、重点观察 | 视觉主角占主体区约 65%–80%，说明环绕但不切碎舞台 | 控件放侧边或底部，反馈贴近发生变化的位置 | 主角被说明卡挤小：删减说明或改为逐步揭示 |
| 偏心主视觉 | 主体与证据、问题或结论有明确主次 | 主视觉约 62%–72%，支持区约 28%–38%；方向随阅读路径变化 | 操作贴近支持区与主视觉交界，反馈回到主视觉 | 固化成左右双栏：交换方向、改上下关系或让支持内容叠入画布 |
| 上下分带 | 建立关系后操作、验证或归纳 | 主舞台约占可用高度 65%–75%，动作与结果带约 25%–35% | 操作和即时反馈共用下带，避免新增第三层 | 两层都是等权文字卡：上层改成关系图，下层只保留动作与结果 |
| 全幅画布 | 场景、地图、坐标、连续空间、就近标注 | 连续画布占主体区约 75%–90%，说明以短标注贴近对象 | 控件轨不超过主体宽度约 25%，或用紧凑底部带 | 外套大白卡压缩场景：移除容器边界，让标注进入连续空间 |
| 左右对照 | 两种状态、方案、过程或观点比较 | 两侧使用同一尺度，常用 1:1；需要关系提示时预留窄中轴 | 共用控制放中轴或底部，反馈同时标出两侧差异 | 内容不可比或尺度不同：先统一变量与基线，无法统一则换偏心结构 |
| 主体加卫星 | 中央对象与部件、证据或影响因素连接 | 中心对象约占主体区 50%–65%，其余空间只放少量可辨认卫星 | 卫星可就近点击，结果回写到中心关系或相邻说明 | 卫星过多变成图标墙：分组、分步或改为序列 / 分层 |
| 横向序列 | 时间、步骤、因果、阶段或递进关系 | 每个阶段必须有可辨认对象或状态差异，连接线服务顺序而非装饰 | 操作放当前节点内或序列下方，反馈标在被改变节点 | 退化成小圆点加长文：放大阶段对象，内容多时改逐步揭示 |
| 矩阵或分层 | 分类、象限、层级、剖面或多变量比较 | 少量单元可用 2×2；层级依靠尺度、嵌套或纵深形成，不靠边框数量 | 控件靠近对应行列或层级，反馈高亮关系而非单格换色 | 单元过多导致内容过小：拆页、改序列或只保留关键比较 |

结构可以组合，但每页最多保留一个主结构和一个辅助关系。例如全幅画布可带窄侧边控制轨，左右对照可包含小型横向序列；不要把三种结构平均叠加成组件拼盘。

## 3. 阅读路径与信息组织

横向推进适合时间、因果和步骤；纵向深入适合分层、推导和从现象到结论；Z 型适合主视觉、证据、行动依次进入视线；放射式适合中心对象与多个关系；环路适合循环过程与反馈；逐层揭示适合复杂结构和分步讲解。

阅读路径由尺度、位置、连接和留白共同形成，不能只依赖编号箭头。语义上不可拆的对象、公式、标签与单位应作为整体换行；一行放不下时整组移动，不通过压缩字距或逐字断行硬塞。

## 4. 操作、变化与反馈

操作位置有四种基本方式：就近操作适合直接操纵，侧边控制适合连续参数，底部动作带适合确认、下一步与重置，节点内操作适合序列和局部判断。控件、发生变化的对象和反馈应形成一个可见因果邻域，避免三者分散在画布不同角落。

静态讲解或总结页没有真实操作时，不要保留空工具栏和伪按钮。互动页在 `initial / longestFeedback / completion` 三态中，操作入口、变化对象、关键反馈都必须完整可见；定位对象要检查完整外接矩形，不只检查中心点是否在画布内。

## 5. 固定画布预算

写 HTML 前，把标题区、主体区、动作区、上下 padding 和全部 gap 明确写入页面生产卡，合计不得超过 540px。下面只是核算示例，不是默认版式：

```text
20 上留白 + 48 标题 + 12 间距 + 360 主体 + 12 间距 + 48 动作带 + 20 下留白 = 520px
```

剩余高度用于边框、极值状态或渲染误差。标题变成两行、反馈增长或完成态新增结果时，必须重新核算，不能让 flex 子项依靠压缩侥幸塞入。

主体高度约 360–380px 时，纵向等权信息组通常不超过三层；更多内容优先改成 2×2、横向步骤、分层揭示或拆页。核心视觉通常承担主体区 55%–75% 的注意力；核心正文和反馈原则上不低于 18px，教学标注与按钮原则上不低于 16px。

## 6. 连续空间与裁切

场景、地图、坐标、过程和关系网络需要连续空间，不应退化为一排外观相同的按钮卡。卡片只用于真实的独立分组；当知识依靠位置、连接或方向成立时，优先保留连续画布。

页面根、主体、反馈和结果区域不得用 `overflow:hidden` 掩盖超量内容。只有纯装饰层可以裁切；学习对象、文字、控件和反馈越界时必须重排、精简、分步或拆页。

## 7. 页面节奏与选择检查

封面或导入页突出核心问题和视觉母题；建模页突出关系；探索或应用页把对象、操作和反馈组成连续舞台；检索页聚焦当前决定；收束页复用前文知识表示形成压缩结构或迁移支架。这是认知动作与构图的匹配，不是固定页型模板。

```text
□ 构图直接支持本页 task.action
□ 视觉主角足够大，没有被通用卡片挤压
□ 阅读顺序可由视觉层级辨认
□ 操作、变化和反馈形成可见因果邻域
□ zones 高度预算不超过 540px
□ initial / longestFeedback / completion 均无越界或滚动
□ 相邻页面没有复制同一完整组合
```
